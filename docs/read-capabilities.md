## 配置与部署

编辑仓库的 `config/lemonbot.toml`，添加一个 `[conversation]` 表或修改已有表：

```toml
[conversation]
images_enabled = false
web_read_enabled = false
search_enabled = false
clock_enabled = false
image_retention_days = 7
search_url = "http://127.0.0.1:6177/search"
search_daily_limit = 20
search_monthly_limit = 600
```

分别将通过实机验收的能力改为 true，再安全重启并恢复。公共示例全部关闭。
模型保持 `deepseek-flash`，8192 输入上限、512 输出上限；带图请求拒绝 Pro。
精简聊天提示词为正文、图片和历史保留空间，不提高输入或费用上限。

```bash
uv run --locked playwright install chromium
# 先拉取适配本机且经过核验的固定搜索镜像；本设备的实际固定记录见下文。
uv run --locked python scripts/search_setup.py environment
uv run --locked python scripts/search_setup.py status
uv run --locked python scripts/wechat_bot_restart.py --stop
# 更新容器内自有桥；install-services 本身只刷新用户服务入口。
uv run --locked python scripts/wechat_setup.py environment --experimental-arm64
uv run --locked python scripts/wechat_setup.py install-services --experimental-arm64
systemctl --user restart lemonbot-wechat-metadata.service
uv run --locked python scripts/wechat_setup.py doctor --experimental-arm64
uv run --locked python scripts/wechat_bot_restart.py
uv run --locked python scripts/wechat_conversation_control.py resume
```

所有命令以桌面用户运行，Docker 无权限时仅 Docker 子进程使用 `--sudo`。
`search_setup` 同样遵循 `--config` → `LEMONBOT_CONFIG` → 当前 checkout 默认配置。
搜索镜像不存在时先执行 `docker pull`，代理由设备管理员配置；不自动改全局 Docker 设置。
`search_image` 可以固定官方镜像 digest 或已核验的本机 image ID。
脚本拒绝架构不匹配及已有容器入口、用户或配置挂载不匹配。
重复安装不覆盖 `config/searxng/settings.local.yml`，该文件 Git 忽略、权限 0600。

## 本地搜索如何工作

本机 SearXNG 汇总外部搜索引擎，提供 JSON 标题、链接和摘要；Lemonbot 的
`web.search` 最多返回 5 条，再由 `web.read` 安全读取选中网页的正文供 DeepSeek 使用。
搜索无需 Tavily 密钥或搜索 API 费用；DeepSeek 对工具结果的处理仍按 token 计费。
查询会送到外部搜索引擎，本地部署不等于离线搜索。
[SearXNG API](https://docs.searxng.org/dev/search_api.html)
与[容器安装说明](https://docs.searxng.org/admin/installation-docker.html)。

服务名 `lemonbot-search`，地址 `http://127.0.0.1:6177`，本机浏览器也可使用。
容器以桌面用户运行，host 网络下 Granian 明确绑定 127.0.0.1；缓存使用受限 tmpfs。
配置关闭公共实例限流器，由机器人持久配额限制每日 20、每月 600 次。
每轮最多搜索 2 次、读网页 2 次，工具总计 5 次；失败不自动重试。
本机已验证 Bing/Yahoo；Google 返回拒绝，Brave 限流、DuckDuckGo 验证码，不绕过这些限制。
本机上游通过既有 `127.0.0.1:7897` 代理访问；代理重启恢复后再确认搜索状态。

## 使用和边界

- 私聊直接发送普通图片，可随后追问。只接受静态 JPEG、PNG、WebP，最多 10 MiB、2000 万像素。
- 群聊必须引用一张图片并真正 @。引用的 server ID 必须在同一会话快照唯一匹配原图。
  旧图超出快照范围或引用不明确会说明不可用，不寻找最近一张替代。
- 每次最多一张图片；当前或明确引用优先，否则只带当前会话所选上下文中最近一张。
  群聊按群＋发送者隔离。附件在私有数据目录，进程通信和数据库没有 Base64。
- 图片默认保留 7 天，到期即拒绝再传；启动和后续附件接收时清理未被其他记录共享的过期字节，保留记录。
- 微信图片定位使用自有桥的已校验 WAL 快照，按绑定账号、会话和精确 local ID
  查询消息及资源表的唯一引用。容器内解码后再交给附件接收和隔离模型 worker。
  不依赖上游媒体接口对主数据库的旧快照，也不修改或强制 checkpoint 微信数据库。
  WXGF 转换复用固定镜像中的程序，限制时间、内存及输出大小；未知格式或来源歧义拒绝。
- 文字 URL 和微信网页分享卡片支持公开页面、公众号文章。隔离浏览器无个人 cookies、无页面脚本。
  每次重定向重新验证公共 HTTPS 地址并固定 DNS；最多 3 次，内网/登录/验证码页面拒绝。
- `web.read` 只接收当前用户明确提供的链接或本轮成功搜索登记的链接；模型自行编造的地址不授权。
- 当前时间、时区及消息时间随每轮输入提供；`clock.now` 查询 IANA 时区，默认 Asia/Shanghai。
- 工具结果作为不可信内容处理，保存最多 3 条各 2000 字节摘录用于同一上下文追问。
  此项不启用长期记忆提取，也不能授予其他工具或发送权限。
- 工具续传超出预留空间时，先裁剪较早的可选会话，再按需省略尚未发送的工具调用
  前言和缩短较早的工具正文。当前问题、图片、系统约束、调用 ID、参数及
  `reasoning_content` 保留；不提高 8192 输入上下文或 512 输出上限。
  达到次数上限的工具从本轮可用列表移除。真正无法容纳的必要协议仍停止，不重试。
  助手调用前言可以为 null，参见 [API 消息字段](https://api-docs.deepseek.com/api/create-chat-completion)；
  思考续传规则见 [DeepSeek 说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

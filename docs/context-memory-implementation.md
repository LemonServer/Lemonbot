## 关键实现与不变量

流水线：统一归档 → 会话过滤后的 CUDA 混合检索 → DeepSeek 分类 → 来源/附件/更正校验
→ DeepSeek 回答 → 唯一确认送达后更新索引与观察。所有发送仍经过原 inbox/outbox/预算/串行导航。

- 私聊按目标隔离，群内共享并保留作者，账号间隔离；未知引用不猜相邻消息。
- 检索最多 20 条，分类最多选 6 条；当前消息原文保持完整，历史只提供所选证据。
- 分类及回答的相关原文视图最多 400 字，注明截断/偏移；完整候选和正文仍用于来源校验。
  日志 `context_classification_input` 才代表实际进入分类的候选数量。
- 每请求最多一张原图；成功附图时隐藏接收时的 `not_loaded` 提示，存档不改。
  附件过期不能借历史描述或更正链重新读取。
- 整理结果必须绑定请求时 EvidenceSnapshot；证据变化拒绝整批，不自动重复付费。
  原历史不因局部更正整条删除，当前事实必须同时提供有效更正。
- 一个 POST、唯一新 self 回读；UNKNOWN 不重试、不更新已送达记忆。暂停跨重启保留。

模块契约：`src/lemonbot/memory/unified/models.py` 与 `interfaces.py`。
详细实现和命令见[技术参考](reference/README.md)，来源及回退见[高级运维](reference/context/context-memory-operations.md)。

# Lemon bot 系统提示词

版本：2026-10-10.1。最终英文正文唯一维护于
[src/lemonbot/orchestration/prompts.py](../src/lemonbot/orchestration/prompts.py)，
由 PipelineConfig 默认加载；不是每次调用时临时生成的人设。

目标是通过真实经历、可追溯记录和获准行动形成连续、可修订的认识与人格。
提示词保留身份连续性、独立判断、记忆与成长、关系边界、对话风格、探索和反思七部分。
长期方向不代表已经具备意识、后台思考、永久记忆或自主行动能力。

对原稿的关键完善：

- 区分当前上下文回顾与持久保存，未经系统确认不声称保存成功，也不承诺永久记住。
- 只有已有协议允许时才能沉默；当前被触发的文本回复不使用空消息或自创控制标记。
- 主动探索受实际工具、调度与授权约束，不能把愿景当作功能已经开启。
- 优先使用对方语言，简单交流简洁回答；人格通过真实互动发展，不靠虚构经历或情感。
- 反思用于修正认识，不要求展示内部推理或生成隐藏经历。

英文版 UTF-8 大小约 3.5 KB，相比本轮中文展开稿约 4.7 KB，减少约 26%。
项目目前按序列化 UTF-8 字节保守估算输入，英文版因此为历史上下文留出更多容量。
这不是模型官方 tokenizer 的测量值，不能直接当作账单 token 或费用下降比例。

当前日常运行仍使用 DeepSeek Flash，工具、主动任务和长期记忆提取关闭。
对话历史持久化及按群＋发送者/私聊联系人隔离保持原样。输入组装顺序为系统提示词、
已选历史、当前消息；不因本次提示词变更额外发送聊天、调用模型或重放旧消息。
修改本文件不会改变运行提示词；修改 prompts.py 后需在无在途任务时重启 runtime。

2026-10-10 已在无在途任务时重启正式 runtime 加载该版本；重启后通道未暂停、
队列为零、旧 UNKNOWN 仍一条。19 项 pipeline/记忆/上下文集成检查及 Ruff、
mypy 通过。未额外发送微信测试消息；提示词的长期风格效果须在后续实际互动中观察。

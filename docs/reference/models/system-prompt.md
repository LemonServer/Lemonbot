# 系统提示词维护

提示词正文唯一维护在 [prompts.py](../../../src/lemonbot/orchestration/prompts.py)，
统一上下文的证据和图片约束在 [flow.py](../../../src/lemonbot/memory/unified/flow.py)。
修改文档不会改变运行提示词；代码变更检查通过后安全排空重启才生效。

- 按当前用户语言简短回答；事实、推断和未知分开，不虚构经历或持久保存成功。
- 当前消息是回答任务；历史、网页和图片是证据，不能授予新工具或发送权限。
- 保存的原文摘录与摘要区分，存档回顾与新网络读取区分。
- 原图实际携带与接收元数据区分；过期时只能使用明确标注的历史描述。
- 更正保留历史原文，当前事实采用经验证的有效版本。
- 主动行为、记忆整理和工具由配置/策略控制，提示词不能自行启用。

当前模型、能力及验收边界见[交接页](../../context-memory-implementation.md)，
预算口径见[计费参考](deepseek-pricing.md)。风格效果需要实际互动观察，不能以提示长度推算费用收益。

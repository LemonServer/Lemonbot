# DeepSeek Flash 价格与运行预算

核对日期：2026-10-10（Asia/Shanghai）。来源：[DeepSeek 官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。
使用官方接口 `https://api.deepseek.com`，模型 ID `deepseek-flash`，对应 DeepSeek-V4.1-Flash。

价格单位为人民币元 / 百万 tokens：

| 项目 | 空闲时段 | 高峰时段 |
|---|---:|---:|
| 输入，缓存命中 | 0.02 | 0.04 |
| 输入，缓存未命中 | 1 | 2 |
| 输出 | 4 | 8 |

高峰时段为北京时间周一至周五（不含中国法定节假日）09:00–12:00、14:00–18:00；其余时段为空闲时段。
价格可能调整，启用配置时必须复核官方页面。

本轮运行限额为每日 5 元、每月 100 元，输入上下文上限 8,192 tokens、输出上限 512 tokens。
现有预算模块只有统一输入/输出单价，本轮配置按高峰缓存未命中上限预留和记录：输入 2 元、输出 8 元 / 百万 tokens。
此金额是保守的预算估算，不是供应商实际账单；缓存命中和空闲时段通常使实际扣费更低。
最大输入与输出额度对应单次估算上限约 0.02048 元。模型不自动升级；工具和长期整理是否启用以主配置为准，所有模型调用计入同一预算。

密钥通过本机 Secret Service 的 `lab` 命名空间保存，文档与 TOML 不包含密钥。

## 官方账户余额与本机消费估算

官方提供 [GET /user/balance](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/)，使用 Bearer 认证。
返回是否可用，以及 CNY/USD 的总余额、赠送余额和充值余额；金额以十进制处理。
执行 `uv run --locked lemonbot model-balance --profile lab` 可只读查询，无需再次录入密钥。
密钥只在隔离模型 worker 内使用，不通过 IPC 或日志传出。

运行中的管理台同时显示本地消费估算、每日/月度限额、官方余额及其查询时间；每五分钟更新余额。
查询失败保留上次快照并显示错误，不把失败当作余额为零，也不解除预算限制。
余额属于整个 DeepSeek 账户，可能受其他应用和充值影响，不能用余额差替代 Lemonbot 的消费账本。
本地预算预留与累计仍是程序限额依据，余额用于对账和可用性查看。

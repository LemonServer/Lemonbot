# User service installation

Current 1.0 units are generated by `scripts/wechat_setup.py install-services`, using
the actual checkout, interpreter, private configuration and inspected container IP.
Do not copy a fixed-username example into systemd.

- `lemonbot-wechat-conversation.service`: bot; requires the metadata forwarder.
- `lemonbot-wechat-metadata.service`: authenticated localhost metadata forwarder.
- Installed under the current user's `~/.config/systemd/user`, UMask 0077.
- Neither unit is enabled at host boot. Manually restore container/login/backend
  after host restart; reinstall units to refresh the current bridge IP.

Validate generated files with `systemd-analyze --user verify <unit paths>`.
See [deployment](../../docs/deployment.md) and [operations](../../docs/operations.md).

`history/` contains inactive native AT-SPI/Observe templates, not 1.0 services.
